# Dungeon Crafting Package Bootstrap

## Goal

Provide a package-standard bootstrap for dungeon-crafting authority.

## Initial Surface

- package descriptor and feature-flag metadata
- explicit authority-boundary metadata
- dungeon-crafting access-state contract
- divine/domain prerequisite contract
- Player System and regional/event guidance-handoff contract
- portable authority-host contract
- recoverable failure-policy and authority-response contracts
- access-state helper
- demo and test scaffolding

## Exclusions

- Player System orchestration
- renderer behavior
- host-world mutation logic
